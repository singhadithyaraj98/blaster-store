🚀 BLASTER STORE | 
Hey there! Thanks for checking out my project. Blaster Store is a premium, tech-focused e-commerce frontend I built for this skill assessment. My goal was to move beyond a "basic" store and create something that actually looks like a high-end brand—sleek, dark, and professional.

🛠️ My Approach
I wanted to build a flow that feels natural for a user. Instead of just listing items, I focused on a "Gaming/Elite Tech" aesthetic (which I call the Blaster Theme). I used React for the logic and Tailwind CSS for the styling to keep the code clean and the UI fast.

What’s inside:
The Storefront: 30+ items categorized so it feels like a real, full-scale shop.

The Flow: You can pick a product, check its details, add it to your "Hangar" (the cart), and go through a full checkout.

The "Buying" Page: I made sure to include all the real-world fields you asked for—Name, Phone, Address, Pincode, and Landmark.

Responsiveness: It’s not just for desktops; I ensured it looks great on a phone too.

💻 Tech I Used
React (Vite): For a lightning-fast development experience.

Tailwind CSS: For that custom "Glassmorphism" and dark-mode look.

React Router v6: To handle all the page navigation smoothly without any flickering.

Vercel: For the live deployment.

📂 Project Structure
I kept the folder structure simple and flat for this assessment so it's easy to navigate:

Home.jsx – The heart of the store.

ProductDetails.jsx – Where the tech specs live.

Cart.jsx – Your pre-purchase summary.

Checkout.jsx – The final logistics form.

Navbar.jsx – That sticky, blurry header that follows you everywhere.

🚀 How to Run It
Grab the code: git clone https://github.com/singhadithyaraj98/blaster-store.git

Install the gear: npm install

Launch: npm run dev
